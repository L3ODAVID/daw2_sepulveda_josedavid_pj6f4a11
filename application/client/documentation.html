Project Documentation

Purpose

StyleStore is a web application for managing clothing orders and customer information.

Application Features

  • User authentication.
  • Create a new customer order.
  • Calculate the order total, including 21% VAT.
  • View all saved orders.
  • Search for an order by its ID.

Technologies

  • HTML5 and CSS3
  • JavaScript
  • PHP
  • JSON file storage
  • Apache web server
