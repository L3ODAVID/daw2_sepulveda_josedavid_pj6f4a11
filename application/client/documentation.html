STYLESTORE PLATFORM

Documentation

Learn how to use the StyleStore clothing order management application.

About the application

StyleStore is a web application designed to manage clothing orders. It allows users to access the platform, create new orders and consult previously registered orders.

02

User authentication

Users must log in with their username and password. The server checks the credentials before allowing access to the application operations.

03

Create an order

The user can enter customer information, select clothing products and specify the quantity of each selected product. The order is sent to the server for processing.

04

Order total and VAT

The server calculates the order total and applies the required 21% VAT. The client displays the result returned by the server.

05

View orders

Users can consult all saved orders or search for an individual order using its order ID.

06

Technologies

  • HTML5 for the application structure.
  • CSS3 for the visual design.
  • JavaScript for client-side interaction.
  • PHP for server-side processing.
  • JSON for storing users and orders.
  • Apache through XAMPP for local development.
